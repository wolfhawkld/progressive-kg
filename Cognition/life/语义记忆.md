# 语义记忆

> 关于世界的一般知识与概念，不依赖获得它的具体时间与地点，与被记住的场合无关

---

## 定义与由来

语义记忆指**关于世界的一般知识**：事实、概念、词义、规则，以及它们之间的组织关系。

它的提出与情景记忆是同一件事的两面：1972 年 Tulving 与 W. Donaldson 在一次关于"组织在人类记忆中的作用"的会议后，Tulving 提出把记忆区分为情景记忆与他所称的**语义记忆**。因此这两个概念从一开始就是成对定义的——理解其中一个必须对照另一个。

### 最关键的一条性质

语义记忆的判定特征不是"内容是事实"，而是：

> **它与获得这条知识的具体时间、地点无关。**

你可能清楚地知道"巴黎是法国首都"，但几乎不可能说出第一次知道这件事是在何时何地。而情景记忆恰恰相反——它的定义就要求带着那个时间地点。（注意：情景记忆随时间会向语义记忆沉淀，所以很多语义知识其实**源自**情景经历，只是已经脱离了原始场合。）

## 与情景记忆的区别

| | 语义记忆 | 情景记忆 |
|---|---|---|
| 内容 | 事实、概念、词义、规则 | 个人经历的具体事件 |
| 时间地点 | **无关**（不依赖获得场合） | **必要**（构成记忆的一部分） |
| 提取体验 | 通常无"重新经历"感 | 伴随回到过去的主观体验 |
| 稳定性 | 相对稳定、少受干扰 | 易受干扰、会随事后信息改变 |
| 共享性 | 与其他人共享的世界知识 | "我"独有的经历 |

一句话概括：**语义记忆是"什么"，情景记忆是"我什么时候经历了什么"。**

### 一个常见的混淆

把"能背出某段话"当成纯语义记忆并不准确。背诵过程往往绑定着具体的学习场景（书桌、讲义、某次课），其中夹着大量情景成分。这也是为什么换了场合就背不出来——你依赖的其实是情景线索。

## 知识的组织

语义知识不是一个个孤立条目，而是**有结构的**：概念之间有层级、类别与关联（"猫"是"动物"的一种，"动物"又属于"生物"）。Tulving 早期的表述把它称为心理上的"分类词典"。

这种组织性正是日常认知效率的来源：能在短时间内处理大量不同信息，靠的是**提取过程有效 + 语义记忆组织良好**，而不是逐个检索。
