# 奇异值（Singular Value）

> 线性映射沿成对正交方向的非负缩放量，用于刻画秩、谱范数、条件数和低秩近似。

## 核心定义

对 $A\in\mathbb R^{m\times n}$，$A^TA$ 是 $n\times n$ 半正定矩阵，其特征值的非负平方根给出奇异值；按常用的矩形 SVD 记号通常列出 $q=\min(m,n)$ 个值，宽矩阵中多出的零特征值由右零空间表示。SVD 为：

$$
A=U\Sigma V^T
$$

其中 $V$ 给出输入空间的右奇异方向，$U$ 给出输出空间的左奇异方向，$\Sigma$ 的对角元素满足 $\sigma_1\ge\sigma_2\ge\cdots\ge0$。

对每对非零奇异方向：

$$
Av_i=\sigma_i u_i
$$

因此可把变换理解为“正交坐标变换 → 按 $\sigma_i$ 缩放 → 正交坐标变换”。

## 几何意义

单位球在 $A$ 下变为椭球或退化椭球，非零奇异值是主半轴长度。零奇异值表示对应方向被压到零。

- $\sigma_1=\|A\|_2$，是欧氏范数下最大放大倍数。
- 非零奇异值个数等于 $\operatorname{rank}(A)$。
- 对方阵或适当的满秩映射，条件数为 $\sigma_{max}/\sigma_{min}$；秩亏时通常记为无穷。

宽矩阵还可能因维度原因存在未显示在紧 SVD 对角线中的零空间，所以解释“最小奇异值是否代表可逆”时必须同时看矩阵形状。

## 与特征值的区别

| 概念 | 对象 | 取值 | 方向关系 |
|---|---|---|---|
| 特征值 | 方阵 | 可为负数或复数 | $Av=\lambda v$，输入输出方向相同 |
| 奇异值 | 任意矩阵 | 非负实数 | $Av_i=\sigma_i u_i$，连接输入和输出正交方向 |

实对称半正定矩阵的奇异值等于其特征值；一般矩阵不能混用二者。

## 低秩近似

保留最大的若干奇异值及其左右方向，可得到给定秩约束下的最佳谱范数或 Frobenius 范数近似。分解形式、截断误差公式与手算例子见 [[奇异值分解#截断分解与误差|奇异值分解的截断近似]]。

这种最佳性针对矩阵重构误差，不保证对下游任务指标也最佳。

## 深度学习中的作用

- 权重 Jacobian 的奇异值会影响局部信号和梯度的放大/缩小；非线性、归一化和层间方向对齐也同样重要。
- 谱归一化通过控制最大奇异值约束线性层的 Lipschitz 上界。
- 权重压缩可用截断 SVD，但实际速度还取决于矩阵形状和 kernel。
- [[Muon优化器]] 对二维隐藏层参数的动量更新做 Newton–Schulz 后处理，以近似极分解的半正交因子；它不是对所有参数执行精确 SVD。

## 奇异值分布的实际意义

比较各奇异值的大小，几乎贯穿所有 SVD 应用的决策：

### 条件数与稳定性

- $\text{cond}(A) = \sigma_{max}/\sigma_{min}$ 度量各方向缩放的不均匀程度。
- 条件数接近 1：各方向缩放均匀，求解稳定；条件数巨大：存在被压得极扁的方向，
  微小输入误差被放大成巨大输出误差 → 数值不稳定。
- 现实例子：神经网络 Hessian 的谱分布很宽时，梯度下降可能在长窄山谷中震荡；这是优化困难的一个来源。动量和自适应优化器还处理噪声、尺度等更广泛的问题，不能据此断言它们总能改善 Hessian 条件数。

### 有效维度与低秩近似

- 奇异值按降序排列，看衰减曲线：若 $\sigma_1 \gg \sigma_2 \approx \cdots \approx 0$，
  矩阵的重构能量集中在少数方向 → 可用低秩近似丢弃小奇异值方向；这只说明矩阵重构误差可能较小，不等于这些方向对下游任务一定无关。
- 现实例子：PCA/降维（保留前 k 个最大奇异值方向）；LLM 权重可用截断 SVD 做固定矩阵的压缩；推荐系统的用户-物品矩阵可做低秩分解。LoRA 与低秩思想相关，但它冻结预训练权重并学习低秩更新 $\Delta W=BA$，不是把预训练权重直接做截断 SVD。

### 主导方向与谱分析

- $\sigma_1$ 对应矩阵作用最强的方向。
- 现实例子：谱归一化约束 $\sigma_{max}$ 控制 Lipschitz 常数（GAN 训练稳定）；PageRank 使用 Google/转移矩阵的主特征向量（通常对应特征值 1），最大奇异值方向是不同对象，不能互换；Muon 优化器压平更新矩阵的奇异值尺度，避免各方向更新幅度失衡。

### 可逆性与正则化

- 对方阵满秩情形，$\sigma_{min}/\sigma_{max}$ 很小表示接近奇异、求解 $Ax=b$ 对误差敏感；仅看 $\sigma_{min}$ 的绝对值不足以判断病态（整体缩放会同时改变所有奇异值），而矩形矩阵还需区分满秩和可逆性的含义。
- 工程上常用 Tikhonov 正则化抑制小奇异值方向对逆问题解的放大，牺牲少量拟合精度换稳定性。对 $A=U\Sigma V^T$ 且惩罚项为 $\lambda^2\|x\|_2^2$ 时，解中的对应因子为 $\sigma_i/(\sigma_i^2+\lambda^2)$；它改变的是逆问题的滤波因子，并没有把 $A$ 的奇异值本身抬高。

### 秩亏与冗余探测

- 小奇异值相对最大奇异值差几个数量级 → 行/列近似线性相关，数据有冗余，
  可降维表示而不损失太多信息。

## Python

```python
import numpy as np

A = np.array([[3.0, 2.0],
              [0.0, 1.0],
              [0.0, 0.0]])
U, s, Vt = np.linalg.svd(A, full_matrices=False)

rank = np.linalg.matrix_rank(A)
spectral_norm = s[0]
```

判断数值秩应使用与数据类型和尺度相适应的容差，而不是固定写死 `1e-8`。
