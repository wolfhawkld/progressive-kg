# 张量（Tensor）

> 具有任意数量轴的 n 维数组的通用数据对象，标量、向量、矩阵是其 0、1、2 阶特例。

## 核心定义

张量是描述具有任意数量轴的 n 维数组的通用方法。就像矩阵是向量的推广，张量把这种推广扩展到任意阶：

| 阶数 | 类型 | 例子 |
|---|---|---|
| 0 阶 | 标量 | 单个数字 |
| 1 阶 | 向量 | 一维数组 |
| 2 阶 | 矩阵 | 二维数表 |
| 3 阶 | 三阶张量 | 时间序列、文本、单张 RGB 图片 |
| 4 阶 | 四阶张量 | 图像批次 |

- 常用 $\mathsf{X}$ 表示，索引如 $x_{ijk}$
- **注意维度语义**：向量的维度指轴的长度（元素个数），张量的维度指轴的数量（阶数）

## 两种视角

张量有两种理解角度，需区分：

- **代数/数据视角**（机器学习常用）：把张量视为 n 维数组，是现代深度学习的基本数据容器（PyTorch、NumPy 的核心结构）
- **几何/物理视角**：张量是不随坐标系变换而改变的几何量，其分量在坐标变换时按规则作线性变换。此时 0 阶为标量、1 阶为向量、2 阶为矩阵（与矩阵的秩/阶概念无关）

### 物理视角的补充

从多重线性映射看，张量是定义在向量空间及其对偶空间笛卡尔积上的多重线性映射。依变换方式分协变（指标在下）、逆变（指标在上）、混合张量三类。工程上应力、二次型等都用张量表示。

## 在机器学习中的角色

- 张量是深度学习中数据与模型的统一表示：权重、激活、批次、注意力分数都以张量存储
- 张量运算（广播、矩阵乘、逐元素）是自动微分与神经网络前向/反向的基础
- "Tensor" 之名也承载了框架命名（TensorFlow、PyTorch）
