# 莱布尼茨公式（Leibniz Formula）

> 乘积的高阶求导公式，把 (fg) 的 n 阶导数展开为二项式式组合，是乘积法则的 n 阶推广。

莱布尼茨公式把**乘积的高阶导数**展开为类似二项式定理的形式——它是乘积法则（一阶）向
任意 $n$ 阶导数的推广。形式上与二项式展开完全对应，只是"幂"换成"求导阶数"。

## 核心定义

对两个 $n$ 阶可导函数 $f$、$g$：

$$(fg)^{(n)} = \sum_{k=0}^{n} \binom{n}{k} f^{(k)}\, g^{(n-k)}$$

- **$\binom{n}{k}$**：二项式系数
- **$f^{(k)}$**：$f$ 的 $k$ 阶导数（$f^{(0)}=f$）
- **直觉**：每一项"轮流把 $f$ 导 $k$ 次、$g$ 导 $n-k$ 次"，再用组合数加权——和二项式
  $(a+b)^n = \sum \binom{n}{k} a^k b^{n-k}$ 结构完全一样

### 特例

- $n=1$：$(fg)' = f'g + fg'$（就是乘积法则）
- $n=2$：$(fg)'' = f''g + 2f'g' + fg''$

## 与二项式定理的类比

莱布尼茨公式是二项式定理在"求导算子"下的对应物，结构完全同源。

- 二项式定理展开 $(a+b)^n$ 的每一项是 $a^k b^{n-k}$，系数 $\binom{n}{k}$
- 莱布尼茨公式展开 $(fg)^{(n)}$ 的每一项是 $f^{(k)}g^{(n-k)}$，系数同样 $\binom{n}{k}$
- **记忆要点**：把"幂"换成"求导阶数"，结构不变——这个类比让公式容易记忆和推广
