# 积分变换（Integral Transform）

> 把函数通过积分核映射到另一表示空间的变换族，傅里叶/拉普拉斯/梅林等变换的上位概念。

积分变换是一类数学变换的统称：通过一个固定的**积分核** $K(s,t)$，把函数 $f(t)$ 映射为
$F(s)$。傅里叶变换、拉普拉斯变换、梅林变换等都是它的特例。核心思想：**换一种表示，让
原本困难的运算（微分、卷积）变简单**。

## 核心定义

一般形式：

$$F(s) = \int_a^b f(t)\, K(s,t)\, dt$$

- **$f(t)$**：原函数（时域/原域）
- **$K(s,t)$**：积分核（决定变换类型）
- **$F(s)$**：变换后函数（变换域）

### 常见特例

| 变换 | 积分核 | 原域 → 变换域 |
| --- | --- | --- |
| 傅里叶变换 | $e^{-i\omega t}$ | 时域 → 频域 |
| 拉普拉斯变换 | $e^{-st}$ | 时域 → 复频域 |
| 梅林变换 | $t^{s-1}$ | 时域 → 复域 |
| 希尔伯特变换 | $\frac{1}{\pi(t-\tau)}$ | 时域 → 时域（相位平移） |

## 统一视角

- **选择不同的核** 就得到不同的变换，服务于不同需求
- **共同优势**：把卷积变乘法、把微分变乘法（拉普拉斯/Z）或频移（傅里叶）
- **线性**：所有积分变换都是线性算子
- **可逆**：多数有对应的逆变换
