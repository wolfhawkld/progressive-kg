# 乘积法则（Product Rule）

> 两函数乘积的求导法则：(fg)' = f'g + fg'，导数家族中最基础的运算规则之一。

乘积法则（也称莱布尼茨法则）是微积分最基础的求导规则：**两个函数乘积的导数，等于
"第一个的导数乘第二个"加"第一个乘第二个的导数"**。它解决了"乘积不能简单拆开求导"
的问题（$(fg)' \ne f'g'$）。

## 核心定义

对可导函数 $f(x)$、$g(x)$：

$$\frac{d}{dx}[f(x)\,g(x)] = f'(x)\,g(x) + f(x)\,g'(x)$$

- **直觉**：$f$ 和 $g$ 都在变。乘积的变化 = $f$ 变 $g$ 不变带来的变化 + $g$ 变 $f$
  不变带来的变化。即"两边各自贡献，加起来"
- **为什么不是 $f'g'$**：$f'g'$ 只算了"两者同时变的二阶项"，漏掉了"一个变一个不变"
  的主贡献

### 推广

- **三函数乘积**：$(fgh)' = f'gh + fg'h + fgh'$（每项轮流只对其中一个求导）
- **n 阶推广**：莱布尼茨公式 $(fg)^{(n)} = \sum_{k=0}^{n} \binom{n}{k} f^{(k)} g^{(n-k)}$
- **商法则可由乘积法则推出**：$(f/g)' = (f'g - fg')/g^2$（把 $1/g$ 看成乘积的一部分）
