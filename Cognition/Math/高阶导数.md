# 高阶导数

> 对函数连续多次求导所得的导数，第n阶导数是导数算子的n次复合。

## 定义与记号

一阶导数 $f'$ 再求导得到二阶导数 $f''$，如此递推得到 $n$ 阶导数 $f^{(n)}$：

- **记号**：$f^{(n)}(x)$、$y^{(n)}$ 或 $\frac{d^n y}{dx^n}$
- **递推定义**：$f^{(n)}(x) = \frac{d}{dx}f^{(n-1)}(x)$
- **零阶约定**：$f^{(0)}(x) = f(x)$

**存在条件**：$n$ 阶导数存在要求 $f$ 至少 $n$ 次可导（前 $n-1$ 阶导函数连续可导）。

## 高阶导数的运算

- **多项式**：$n$ 次多项式的 $n$ 阶导数为常数，更高阶为 0
- **常见函数**：$(e^x)^{(n)} = e^x$；$(\sin x)^{(n)} = \sin(x + n\frac{\pi}{2})$
- **乘积**：$(fg)^{(n)}$ 用莱布尼茨公式，系数为二项式系数
- **链式**：复合函数高阶导用 Faà di Bruno 公式（较复杂）

## 应用

- **泰勒展开**：泰勒级数系数 $f^{(n)}(a)/n!$ 直接由高阶导数给出
- **极值判定**：一阶导为零处，用二阶导符号判断极大/极小（二阶导数判定法）
- **凸性分析**：$f''(x)$ 的符号决定函数凹凸性
- **微分方程**：高阶线性微分方程的解依赖高阶导数
- **深度学习**：Hessian 矩阵（二阶偏导矩阵）用于优化分析与二阶方法
