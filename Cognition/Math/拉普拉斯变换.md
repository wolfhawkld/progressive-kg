# 拉普拉斯变换（Laplace Transform）

> 把时域函数映射到复频域的积分变换，将微分运算变为乘法，是求解微分方程与线性系统的利器。

拉普拉斯变换（Laplace transform）是一种积分变换：把时间函数 $f(t)$ 映射为复频率函数
$F(s)$（$s$ 为复变量）。它的核心价值：**把微分方程变成代数方程**——微分运算在变换后变成
乘法，从而大大简化线性微分方程和线性时不变系统的分析。得名自法国数学家拉普拉斯。

## 核心定义

对定义在 $[0,\infty)$ 上的函数 $f(t)$，其拉普拉斯变换为：

$$F(s) = \int_{0}^{\infty} f(t)\, e^{-st}\, dt$$

- **$f(t)$**：时域函数（输入，通常是时间信号）
- **$s = \sigma + i\omega$**：复频率变量（复平面）
- **$F(s)$**：复频域函数（输出）
- **收敛条件**：积分需收敛，通常要求 $f(t)$ 满足一定增长条件（$\sigma$ 足够大时收敛）
- **逆变换**：从 $F(s)$ 还原 $f(t)$（通常查表 + 部分分式，或 Bromwich 积分）

常用变换对（查表）：

| $f(t)$ | $F(s)$ |
| --- | --- |
| $1$ | $1/s$ |
| $e^{at}$ | $1/(s-a)$ |
| $t^n$ | $n!/s^{n+1}$ |
| $\sin(\omega t)$ | $\omega/(s^2+\omega^2)$ |
| $\delta(t)$ | $1$ |

## 与傅里叶变换的关系

**拉普拉斯变换是傅里叶变换的推广**：

- 傅里叶：$\int f(t) e^{-i\omega t} dt$（频率在纯虚轴 $i\omega$ 上）
- 拉普拉斯：$\int f(t) e^{-st} dt$（频率在整个复平面 $s=\sigma+i\omega$）

关系：拉普拉斯 = 傅里叶 + 实部收敛因子 $e^{-\sigma t}$。多出的实部 $\sigma$ 让拉普拉斯能
处理傅里叶搞不定的**非绝对可积、指数增长**的函数（很多工程信号）。傅里叶是拉普拉斯在
$\sigma=0$（纯虚轴）上的特例。

**与幂级数的关系**：拉普拉斯变换可看作幂级数的连续模拟——把离散求和 $\sum a_n x^n$
换成连续积分 $\int f(t) e^{-st} dt$（改变底并做变量替换）。

## 关键性质：微分变乘法

这是拉普拉斯变换最核心的性质，也是它解微分方程的根据：

$$\mathcal{L}\left[\frac{d^n f}{dt^n}\right] = s^n F(s) - s^{n-1}f(0^+) - \cdots - f^{(n-1)}(0^+)$$

- **微分 → 乘 $s$**：把 ODE 中的导数换成代数项，微分方程变为代数方程
- **解方程流程**：对 ODE 两边取拉普拉斯 → 解代数方程得 $F(s)$ → 逆变换还原 $f(t)$
- **初值/终值定理**：无需完整逆变换即可得 $f(0^+)=\lim_{s\to\infty}sF(s)$、
  $f(\infty)=\lim_{s\to0}sF(s)$（满足特定极点条件时）
