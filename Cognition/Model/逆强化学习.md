# 逆强化学习（Inverse Reinforcement Learning）

> 从专家示范轨迹中推断其背后的奖励函数，再用该奖励做强化学习以获得更可泛化的策略。

逆强化学习（IRL）走的是**反方向**的路：不直接学"专家怎么做"（那是行为克隆），而是先问
**"专家为什么这么做"**——从示范轨迹中推断出一个能解释专家行为的**奖励函数**，然后用这个
奖励函数去做常规强化学习。它的动机很实际：**手工设计奖励函数往往比提供示范难得多**，
既然专家行为背后必有奖励在驱动，不如把它反推出来。

## 核心思想

- **输入**：专家示范轨迹（不提供奖励信号）
- **输出**：一个奖励函数 $R^*$（使专家策略在该奖励下最优）
- **再学习**：用推断出的 $R^*$ 跑标准 RL，得到策略

**关键优势**：学到的是**奖励**而非单纯的动作映射。奖励是比动作更抽象、更可迁移的表示——
同一个"不要撞车"的奖励可以泛化到新路况，而逐步动作映射（BC）做不到。

### 根本困难：不适定问题

**奖励函数不唯一**——"什么都不做"也是某些奖励下的最优策略；无穷多奖励函数都能解释同一
段示范（甚至常数奖励让所有策略等价）。因此 IRL 必须引入**偏好假设/正则化**来挑出一个解，
常见思路：

- **最大边际（max-margin）**：让专家策略比其它策略的回报高出一定间隔
- **最大熵 IRL**：在所有能解释示范的奖励中，选使示范轨迹分布熵最大的那个（不引入额外偏好）
- **对抗式方法**：用判别器隐式表示奖励（见 GAIL）

### 计算代价

IRL 是**双层优化**：内层用当前奖励跑 RL 求策略，外层根据策略与专家的差异修正奖励。
这比直接 RL 昂贵得多（每轮外层都要完整解一次内层 RL），是 IRL 实用化的主要障碍。
