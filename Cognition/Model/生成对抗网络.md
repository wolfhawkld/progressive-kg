# 生成对抗网络（GAN）

> 由生成器与判别器构成对抗博弈、通过极小极大优化学习数据分布的生成模型框架。

生成对抗网络（GAN, Goodfellow et al. 2014）用一个**对抗博弈**来学习数据分布：**生成器**
（Generator）努力造出以假乱真的样本，**判别器**（Discriminator）努力分辨真伪。两者在训练中
互相促进——判别器越来越会鉴别，生成器越来越会造假，最终生成器的输出逼真到判别器无法区分。
它是深度生成模型的奠基框架之一。

## 核心结构

- **生成器 $G$**：输入随机噪声 $z$，输出合成样本 $G(z)$；目标是**捕捉真实数据的特征分布**
- **判别器 $D$**：二分类器，输入样本输出"真/假"概率（1 = 真，0 = 假）
- **连接方式**：$G$ 的输出直接接入 $D$ 的输入，**通过反向传播**把 $D$ 的判别信号传回 $G$
  更新其权重

### 极小极大博弈

$$\min_G \max_D \mathbb{E}_{x\sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z}[\log(1-D(G(z)))]$$

- **$D$ 的目标**：最大化判别准确率（真假都判对）
- **$G$ 的目标**：最小化 $D$ 的判别能力（让 $D(G(z)) \to 1$）
- **均衡点**：达到纳什均衡时 $D$ 无法可靠区分真伪

**直觉类比**：假币制造者（$G$）与警察（$D$）的军备竞赛——双方都持续变强，直到伪钞以假乱真。

## 特点与常见变体

**优势**：无需显式建模概率密度、可生成高保真样本、无监督或半监督可用

**训练难点**：**不稳定**是 GAN 的著名问题（模式崩溃 mode collapse、判别器过强导致梯度消失），
通常需要仔细调超参

| 变体 | 特点 |
| --- | --- |
| **cGAN** | 加条件（如文本），可控生成 |
| **DCGAN** | 用卷积网络做 $G$/$D$（生成器用转置卷积） |
| **CycleGAN** | 非配对图像到图像转换（马→斑马） |
| **StyleGAN** | 高分辨率人脸生成，可精细控制风格 |
| **SRGAN** | 超分辨率（低清→高清） |

## 在强化学习中的借用

GAN 的对抗框架被移植到模仿学习，产生**对抗式模仿学习**：

- **GAIL**（Generative Adversarial Imitation Learning）：让判别器区分"专家轨迹"与"策略轨迹"，
  策略努力骗过判别器——绕过了 IRL 显式推断奖励的困难，直接匹配**状态-动作分布**
- 本质：用对抗训练隐式表示奖励函数，从而规避 IRL 的双层优化代价
