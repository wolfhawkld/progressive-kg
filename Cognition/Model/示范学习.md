# 示范学习（Learning from Demonstration）

> 从专家示范数据中直接学习策略，使智能体模仿专家行为，是奖励信号难以定义时的主要替代路线。

示范学习（Learning from Demonstration, LfD），又称**模仿学习**（Imitation Learning）或学徒学习
（Apprenticeship Learning）：智能体不通过试错获得奖励信号，而是**观察专家的示范轨迹**
（通常是 $(s,a)$ 对），学出一个能模仿专家行为的策略。它的价值主张很直接——**手工设计一个
好的奖励函数往往比提供专家示范难得多**，所以"抄"是更务实的路线。

## 核心问题：没有奖励信号

| | 标准强化学习 | 示范学习 |
| --- | --- | --- |
| 学习信号 | 环境给出的奖励 $r$ | 专家的动作示范 $(s,a)$ |
| 数据来源 | 自主试错交互 | 预收集的专家轨迹 |
| 核心难点 | 奖励设计、探索效率 | **分布偏移**（见下） |
| 适用场景 | 奖励可定义 | 奖励难定义/难设计 |

示范学习的设定通常包含三个条件：能拿到预收集的专家轨迹、能与环境交互（常有模拟器）、
**拿不到奖励信号**。

## 主要方法

示范学习的方法谱系可以按"学什么"分成三条线：直接学动作映射（BC）、迭代修正数据分布
（DAgger）、先推断奖励再学策略（IRL/AIL）。

### 行为克隆（Behavior Cloning, BC）

最直接的路线：**把示范数据当作监督学习**，学习状态到动作的映射。

- 目标：最小化智能体策略与专家策略的动作差异，归约为回归或分类任务
- 优点：实现简单（有现成的监督学习工具）
- **致命问题：分布偏移 / 复合误差（compounding error）**——训练时只见过专家的状态分布，
  部署时一旦偏离就进入未见过的状态，错误不断累积放大
- 信息论视角：在"只给固定专家数据集"的问题设定下，**任何算法**最坏情况都会有复合误差

### DAgger（Dataset Aggregation）

针对 BC 的分布偏移提出的迭代数据聚合算法：

1. 用当前策略与环境交互，产生新轨迹
2. 对策略**自己访问到的状态**向专家咨询动作，构成新数据
3. 把新数据并入训练集，重新用 BC 训练
4. 重复上述过程

关键点：**换的不是模型而是数据收集闭环**——让专家为策略实际会遇到的状态打标签，
从而减少"未访问状态"的数量，缓解复合误差。DAgger 基于**在线学习**框架。

### 逆强化学习（Inverse Reinforcement Learning, IRL）

反其道而行：**先从示范中推断出专家的奖励函数**，再用该奖励函数做强化学习。

- 思路：专家行为背后必有某个奖励函数在驱动，先恢复它，再最大化它
- 优点：学到的是奖励而非单纯动作映射，泛化性更好
- 缺点：双层优化（内层 RL、外层奖励拟合），**计算复杂度高**

### 对抗式模仿学习（Adversarial Imitation Learning）

核心思想是**状态-动作分布匹配**，用 GAN 式的极小极大优化：

- 判别器区分"专家轨迹"与"策略轨迹"，策略努力骗过判别器
- 代表算法 **GAIL**（Generative Adversarial Imitation Learning）
- 优势：直接匹配占用度量（occupancy measure），比 BC 更抗分布偏移

## 应用

- **机器人控制**：机械臂操作、运动技能学习（遥操作/MoCap 采集示范）
- **自动驾驶**：从人类驾驶数据学习（早期无人车已用浅层网络 + 人类示范穿越北美）
- **游戏 AI**：AlphaGo 用人类棋谱做模仿学习（之后再用自我对弈强化）
- **推荐系统 / 网约车派单**：构建虚拟世界，允许智能体在其中试错学习
