# 马尔可夫网络（Markov Network）

> 用无向图表达变量间局部依赖的概率图模型，与贝叶斯网络（有向）相对。

马尔可夫网络（马尔可夫随机场，MRF）是**无向**概率图模型：节点是随机变量，无向边表示
"局部相互作用"，没有方向（不表达因果）。联合分布用**团（clique）上的势函数**（因子）
的乘积表示。与贝叶斯网络（有向、可表达因果）相对，马尔可夫网络适合表达**对称的、无
方向**的依赖关系（如图像像素、社交网络）。

## 核心定义

无向图 $G=(V,E)$，变量 $X_V$ 的联合分布用势函数（因子）乘积表示：

$$P(x_V) = \frac{1}{Z} \prod_{c \in \mathcal{C}} \phi_c(x_c)$$

- **$\phi_c(x_c)$**：团 $c$ 上的势函数（非负，无需归一化为概率）
- **$\mathcal{C}$**：图中所有极大团（maximal cliques）的集合
- **$Z$**：配分函数（归一化常数）$Z = \sum_x \prod_c \phi_c(x_c)$

### 条件独立（马尔可夫性）

- 给定某个变量的**马尔可夫毯**（邻居 + 邻居的邻居），该变量与图中其余部分独立
- 无向图表达的是"局部对称依赖"，与有向图的因果方向不同

## 与贝叶斯网络对比

| | 马尔可夫网络 | 贝叶斯网络 |
| --- | --- | --- |
| 图 | 无向 | 有向无环（DAG） |
| 依赖 | 对称、局部 | 方向、因果 |
| 表示 | 势函数乘积 / 配分函数 | 条件概率乘积 |
| 难点 | 配分函数难计算 | 结构学习 |
| 典型应用 | 图像/空间数据 | 因果关系、专家系统 |
