# 贝叶斯推断（Bayesian Inference）

> 用贝叶斯定理结合先验与数据更新对参数或假设的信念，是贝叶斯定理的方法论延伸。

贝叶斯推断是把贝叶斯定理当作系统方法论来用：对未知参数 $\theta$ 持有先验信念
$P(\theta)$，观察到数据 $D$ 后用贝叶斯定理更新为后验 $P(\theta|D)$。它把"统计推断"变成
"信念更新"的过程，是贝叶斯统计的核心。

## 核心定义

$$P(\theta \mid D) = \frac{P(D \mid \theta)\, P(\theta)}{P(D)} \propto P(D \mid \theta)\, P(\theta)$$

- **先验 $P(\theta)$**：看到数据前对参数的信念
- **似然 $P(D|\theta)$**：给定参数下数据出现的概率（模型规范）
- **后验 $P(\theta|D)$**：结合数据后对参数的最新信念
- **证据 $P(D)$**：归一化常数（常省略，用正比形式）

## 推断过程

- 选择先验与似然模型 → 计算后验（或采样后验）→ 用后验做点估计/区间估计/预测
- **顺序更新**：上一轮的后验可作为下一轮的先验（数据越多越准）
- **先验的作用**：信息量大的先验需更多数据才能改变；信息量小的先验影响小
- **计算**：后验常无闭式解，用 MCMC / 变分推断近似采样

### 与频率学派的对比

- 频率学派：参数是固定未知常数，用置信区间/假设检验（"数据产生概率"视角）
- 贝叶斯学派：参数是随机变量，用后验分布/可信区间（"信念"视角）
- 频率学派批评先验主观；贝叶斯学派认为不确定性应显式建模
