# 自回归建模

> 按指定顺序把联合分布分解为逐项条件分布，并用已给定的前缀预测后续变量的建模方式。

## 用概率链式法则建模

对固定长度的离散序列，精确的链式分解是

$$p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t}).$$

模型用参数化条件分布近似这些因子；分解本身不要求只看最近一步，也不要求模型是RNN。可变长度文本常通过终止token表达停止。

例如模型给出$p(A)=0.6$、$p(B\mid A)=0.5$，则两项序列$(A,B)$的概率为0.3。条件概率要在每个前缀下各自归一化。

## 训练与生成的区别

以观测序列作为前缀时，最大似然训练等价于最小化各位置的负对数条件概率之和：

$$\mathcal L(\theta)=-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).$$

在因果掩码Transformer中，训练可同时计算多个位置；普通逐token生成时，后一个位置依赖前一个已选结果。训练并行不意味着普通生成可以一次独立产生所有位置。

- Teacher forcing提供真实历史；生成时历史包含模型自己的输出，错误可能累积。
- KV Cache减少重复计算，不改变这个概率分解。
- 解码可以采样或搜索；高似然不等于事实正确或任务最优。

## 与其他序列模型的边界

自回归是一种概率组织方式，Transformer和RNN是可用于实现它的架构。

传统时间序列中的AR(p)常写为$x_t=c+\sum_{i=1}^{p}a_ix_{t-i}+\epsilon_t$，它是有限阶线性设定，不等于所有神经自回归模型。本页不将AR(p)作为无条件同义词。

改变变量顺序会改变条件建模难度；双向掩码预测也不能直接当作同一左到右联合分布的训练目标。
