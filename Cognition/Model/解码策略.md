# 解码策略

> 依据模型给出的条件分布，通过搜索或采样选择输出序列的规则。

## 模型分布与输出选择

模型输出条件分布，解码规则决定实际选取哪个token或候选序列。它与分词器将编号解码成文字的操作不同。

| 规则 | 选择方法 | 主要边界 |
|---|---|---|
| 贪心 | 每步取最大概率token | 局部最大不保证整个序列概率最大 |
| 束搜索 | 保留有限个高分前缀 | 搜索仍近似，长度惩罚会改变评分目标 |
| 全分布采样 | 按条件概率随机抽取 | 可能抽到不合适的尾部候选 |
| Top-k | 只在最高的k个候选中重归一化 | 固定数量不适应分布尖锐程度 |
| Top-p | 保留累计概率达到阈值的最小排序前缀 | 候选数量随当前分布变化 |

## 温度与截断示例

对有限logits $z_i$ 和温度$\tau>0$，采样分布为

$$q_i=\frac{e^{z_i/\tau}}{\sum_j e^{z_j/\tau}}.$$

若原分布是$(0.6,0.3,0.1)$，Top-p阈值0.8保留前两个候选，重归一化为$(2/3,1/3,0)$。温度趋近0的极限会集中到最大logit，但不能把0直接代入上述除法公式。

另设两步生成中$p(A)=0.6,p(B)=0.4$，A之后最高条件概率为0.5，B之后最高为0.9。贪心先选A得到0.3，而从B出发可得0.36，说明逐步贪心不保证全局最优。

## 评估与实现约定

解码应按任务评价：开放创作关注多样性，结构化输出关注约束满足，事实问答还需证据核对。

- 温度调节不等于概率校准，也不能修复模型不知道的事实。
- 停止符、长度上限、禁用token及重复惩罚都会影响结果。
- Top-k、Top-p、温度同时使用时应记录处理顺序、并列分数规则及实现版本。
- 原论文中的退化现象是给定模型和任务的证据，不能推出某种策略在所有任务最优。
