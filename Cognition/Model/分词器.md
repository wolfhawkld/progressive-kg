# 分词器

> 把文本按既定规则编码为离散token及其编号，并提供相应解码规则的组件。

## 从文本到编号

分词器解决离散编码，词嵌入解决编号到向量的映射。token可以是字节、字符、子词或词，不能用“一个汉字或一个英文单词”作为通用计数规则。

常见处理链如下，各阶段是否启用由具体分词器决定：

```text
文本 → 规范化 → 预切分 → 子词/词模型与词表映射 → 特殊token处理 → 编号序列
```

规范化可能改变大小写或字符表示；解码因而不保证恢复输入的每个原始字符。分词规则、词表编号和模型的嵌入表必须匹配。

## 子词方法与最小例子

BPE根据训练语料中的符号对统计学习合并规则，编码时应用已学到的规则；WordPiece与Unigram使用不同的训练或分解准则，不能统称为同一个算法。

本页构造一个教学词表，设`low`编号为7、`er`编号为9，且规则把`lower`分为这两个片段，则编码是`[7,9]`，token数为2。嵌入层再取矩阵的第7、9号行。这里的编号仅用于演示，不对应任何真实模型。

- 训练分词器与训练语言模型是不同过程。
- 子词减少对整词词表的依赖，但未知字符处理仍取决于字节覆盖、回退或未知符号策略。
- 用不同分词器比较每token困惑度时，单位不同，不能直接横比。

## 长度与接口边界

同一文本在不同词表下可能有不同长度，进而改变上下文预算及注意力计算成本。

- 特殊token可能参与长度计数，需区分模型输入与用户可见文本。
- 截断和填充是输入组织策略，不能默认为自然语言分词的一部分。
- 分词器的decode只把编号还原为文本；生成时如何选择编号由解码策略决定。
