# 优先经验回放（Prioritized Experience Replay）

> 按 TD 误差大小对经验加权采样，优先重放学得更多的转移，以提升样本利用效率。

优先经验回放（PER, Schaul et al. 2015）是经验回放的改进：把"均匀随机采样"换成
**按学习价值加权采样**。核心观察很简单——**TD 误差大的转移说明当前估计还错得离谱，
从中学到的信息最多**；反复抽已经学会的样本是浪费。所以 PER 用 TD 误差作为优先级。

## 核心机制

- **优先级定义**：$p_i = |\delta_i| + \epsilon$（$\delta_i$ 为该转移的 TD 误差，$\epsilon$ 保证非零）
- **采样概率**：$P(i) = p_i^{\alpha} / \sum_k p_k^{\alpha}$
  - $\alpha = 0$：退化为均匀采样；$\alpha = 1$：完全按优先级
- **重要性采样校正**：优先采样改变了数据分布，会引入偏差，故用权重
  $w_i = (1/(N \cdot P(i)))^{\beta}$ 校正，$\beta$ 从初始值逐渐退火到 1
- **优先级更新**：每学到新的 TD 误差后回写优先级

### 两个关键设计考量

1. **纯贪心优先级的风险**：只抽 TD 误差最大的几条会导致样本多样性崩坏、易过拟合
   → 用 $\alpha$ 做指数插值，在"均匀"与"完全优先"之间平衡
2. **偏差-方差权衡**：优先采样提升收敛速度（更快聚焦难样本），但引入分布偏差
   → 重要性采样权重的 $\beta$ 退火在训练后期逐步消除偏差

## 与 DDQN 的关系

PER 与 DDQN 是**正交**的 DQN 改进，常组合使用：

| 改进 | 修正什么 | 层面 |
| --- | --- | --- |
| DDQN | Q 值**估计准确性**（高估偏差） | 目标计算 |
| PER | **样本利用效率**（采样分布） | 数据采样 |

两者结合（DDQN + PER）是 Atari 上常见的强基线组合。
