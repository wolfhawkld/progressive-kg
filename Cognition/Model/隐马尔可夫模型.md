# 隐马尔可夫模型

> 状态不可直接观测、只能通过观测序列间接推断的马尔可夫模型，广泛用于序列建模。

## 核心思想

隐马尔可夫模型（HMM）是马尔可夫性质在观测序列建模中的应用。系统内部状态构成马尔可夫链，但状态本身不可观测，只能通过观测序列间接推断：

- **隐藏状态**：$z_1, z_2, ..., z_T$ 构成马尔可夫链（满足马尔可夫性质）
- **观测**：$x_1, x_2, ..., x_T$，每个观测由对应隐藏状态按发射概率生成
- **独立性假设**：给定当前状态，观测与其他状态和观测独立

## 三大基本问题

HMM 的三个基本问题构成其应用框架：

- **评估（Evaluation）**：给定模型，计算观测序列概率——用前向算法（Forward Algorithm）
- **解码（Decoding）**：给定观测序列，求最可能的隐藏状态序列——用维特比算法（Viterbi Algorithm）
- **学习（Learning）**：从观测序列估计模型参数——用 Baum-Welch 算法（EM 特例）

## 应用

- **语音识别**：音素/词序列建模
- **生物信息学**：基因注释、蛋白质结构预测
- **自然语言处理**：词性标注、命名实体识别（传统方法）
- **时序建模**：金融、信号处理中的状态估计
