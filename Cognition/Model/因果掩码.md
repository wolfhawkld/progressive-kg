# 因果掩码

> 在序列注意力中限制位置只能读取当前及先前输入位置的掩码，防止使用未来信息

## 注意力的可见范围

标准从左到右的因果自注意力为每个查询位置规定可读取的键位置，再对可见位置归一化。

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V,\qquad
M_{ij}=\begin{cases}0,&j\le i\\-\infty,&j>i.\end{cases}
$$

三个位置的加性掩码为 $M=\begin{pmatrix}0&-\infty&-\infty\\0&0&-\infty\\0&0&0\end{pmatrix}$。禁止位置在 softmax 后权重为零。

## 训练对齐与实现边界

掩码必须配合输入和目标的移位：若输入位置 $i$ 是 $x_i$，该位置预测 $x_{i+1}$，可读取 $x_i$ 不等于读取待预测标签。

- 教师强制训练可并行计算全部位置；掩码限制信息访问，生成时仍逐步产生未知 token。
- padding 掩码隐藏填充位置，因果掩码隐藏未来位置，两者用途不同，可能需要组合。
- 带 KV Cache 时，查询与键长度可能不同，应按真实序列位置对齐，不能机械套用方形矩阵。
- 各 API 的布尔掩码真值语义可能相反；全被屏蔽的一行也需单独处理，不能假定 softmax 会自动给出有效分布。
- 此处“因果”指序列信息约束，不意味着模型已识别现实世界的因果效应。
