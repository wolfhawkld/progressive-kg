# 碱基对

> 核酸中两个通过氢键形成特定相互作用的碱基组合，也常作为双链DNA序列长度的计量单位。

## 互补配对规则

典型 DNA 双螺旋采用 Watson–Crick 配对：一条链上的 A 对应另一条链的 T，G 对应 C。

| 配对 | 常规配对中的氢键数 |
|---|---:|
| A–T | 2 |
| G–C | 3 |

- 典型 DNA 双螺旋中的配对跨越两条反向平行链；RNA 折叠时，互补碱基也可在同一条链内配对。无论哪种情形，配对都不同于同一链内相邻核苷酸之间的磷酸二酯键。
- 双螺旋的稳定性还涉及相邻碱基的堆积相互作用，不能只用氢键数解释。
- 配对时还必须考虑两条链的反平行方向，不能只替换字母而忽略 5′/3′。
- RNA 中也存在碱基配对，常规配对包括 A–U 与 G–C；“碱基对”并非只适用于 DNA。

## bp 是怎样计数的

`bp` 是 base pair 的长度单位，计数沿双链排列的配对位置，而不是把两条链上的核苷酸全部相加。

```text
5′-A T G C-3′
   | | | |
3′-T A C G-5′
```

本页示例有 **4 bp**：每条链各有 4 个核苷酸，整个完全配对的双链片段共 8 个核苷酸。

- 1 kbp = 1,000 bp；1 Mbp = 1,000,000 bp。
- 描述单链 DNA 或 RNA 长度时常用 `nt`（nucleotide，核苷酸），避免误以为都已配对。
- 测序结果只列出一条链的序列，也可用 bp 表示所对应的双链 DNA 区段长度。

## 碱基对不等于密码子

碱基对是结构或长度单位，密码子是沿 mRNA 的一个阅读框连续读取的三个核苷酸。

| 概念 | 描述什么 |
|---|---|
| 一个碱基对 | 两个相互配对的碱基 |
| 一个密码子 | 单条 mRNA 上有序的三核苷酸组合 |
| 一个氨基酸残基 | 多肽链中的一个构件 |

标准遗传密码中，有些密码子指定氨基酸，有些表示终止。只有明确编码区域、阅读框、RNA 加工及终止位置后，才能讨论 DNA 长度与蛋白质长度的关系，不能把任意 DNA 的 bp 数直接除以 3 当作氨基酸数。
