# 多糖

> 由大量单糖或其衍生物经糖苷键连接形成的碳水化合物聚合物，可承担储能、结构和细胞识别等功能。

## 组成与连接方式

多糖是由大量单糖或单糖衍生物重复连接形成的聚合物。单元之间通常以糖苷键相连；连接位置、α/β 构型、支化程度和单体种类共同决定链的形状与性质。

| 结构维度 | 可能情况 | 影响 |
|---|---|---|
| 单体 | 同一种单糖，或多种糖及其衍生物 | 决定化学组成和官能团 |
| 链形 | 线性或支化 | 影响堆积、溶解和酶可及性 |
| 糖苷键 | α 或 β，不同连接位置 | 影响螺旋、延展链和材料强度 |
| 作用 | 储能、支撑、屏障或识别 | 由结构与细胞环境共同决定 |

这里的“多”是结构分类，不是说所有多糖都有相同分子量、溶解性或生物功能。

## 储能型与结构型

同样由葡萄糖构成的聚合物，也可能因为连接方式和支化程度不同而承担不同作用。

| 代表 | 主要单体或结构 | 典型作用 |
|---|---|---|
| 淀粉 | 葡萄糖聚合物，含直链和支化组分 | 植物储存葡萄糖 |
| 糖原 | 高度支化的葡萄糖聚合物 | 动物和许多微生物储能 |
| 纤维素 | β(1→4) 连接的线性葡萄糖链 | 植物细胞壁结构 |
| [[几丁质]] | β(1→4) 连接的 N-乙酰葡萄糖胺链 | 真菌细胞壁和节肢动物外被结构 |

结构型多糖的链可以通过氢键等相互作用形成纤维或复合材料；储能型多糖的支化结构则有利于在需要时从多个末端动员单体。功能不能只由“它是糖”或“它是聚合物”推断。

## 合成、降解与细胞作用

单糖连接成糖苷键通常需要活化的供体和酶促过程；分解多糖则常通过水解切断糖苷键，产生较短的寡糖或单糖。不同生物是否拥有相应酶，决定了某种多糖能否被利用或降解。

- 多糖可作为细胞内的能量储备，降低大量游离单糖造成的渗透压问题。
- 线性和交联结构可构成细胞壁、外被或细胞外基质的支撑与屏障。
- 糖链表面的结构还能参与细胞识别、黏附和分子运输定位。
- “可降解”取决于具体糖苷键、酶和环境，不能把所有多糖视为同样容易分解的材料。

## 与其他生物大分子的边界

多糖的重复单元是糖或糖衍生物，主要通过糖苷键连接；[[蛋白质]]的重复单元是[[氨基酸]]，通过肽键连接；[[DNA]] 和 [[RNA]] 则由[[核苷酸]]通过磷酸二酯键形成。它们都能形成长链，却使用不同的构件、连接化学和信息机制。

[[几丁质]]是多糖的一个具体例子，而不是“所有多糖”的同义词。几丁质的含氮乙酰氨基来自 N-乙酰葡萄糖胺这一糖衍生物，不能因此把它归为蛋白质或氨基酸聚合物。
