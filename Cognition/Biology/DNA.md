# DNA

> 由脱氧核糖核苷酸连接成链、以碱基序列储存遗传信息的核酸，在细胞中通常呈双链结构。

## 从核苷酸到 DNA 链

DNA 的基本构件是脱氧核糖核苷酸，每个构件含磷酸、脱氧核糖和一个含氮碱基；碱基只是核苷酸的一部分。

| 碱基 | 中文名 | 类型 |
|---|---|---|
| A | 腺嘌呤 | 嘌呤 |
| T | 胸腺嘧啶 | 嘧啶 |
| G | 鸟嘌呤 | 嘌呤 |
| C | 胞嘧啶 | 嘧啶 |

同一条链上，相邻核苷酸通过磷酸二酯键连接，形成糖—磷酸骨架。5′ 与 3′ 表示糖上碳原子的位置，由此规定链的方向；序列通常按 5′→3′ 书写。

## 互补双链与复制

典型双链 DNA 中，两条链反向平行，碱基朝向内部并互补配对；详细规则和长度单位见 [[碱基对]]。

```text
5′-A T G C C A-3′
   | | | | | |
3′-T A C G G T-5′
```

- 两条链不是按同一方向书写的相同字符串；本例下链若也按 5′→3′ 写，应为 `TGGCAT`。
- 配对关系使一条链能为另一条链的合成提供序列模板，但复制仍依赖聚合酶等分子机器。
- 半保留复制形成的每个子代双链分子各含一条旧链和一条新链；复制与修复并非永远无误。

## 遗传信息与蛋白质的联系

DNA 碱基的排列可提供合成 RNA 的信息。对于蛋白质编码区域，信息经转录产生 RNA，再由翻译过程指定氨基酸的排列。

```text
DNA 中的编码信息 → RNA → 氨基酸序列构成的多肽
```

- 这是信息传递关系，不是把 DNA 分子直接变成氨基酸。
- 不是所有 DNA 都编码蛋白质；部分序列参与调控，部分产生具有功能的非编码 RNA。
- 单个序列片段是否被表达、何时表达以及表达多少，还受细胞状态和调控过程影响。

## 与其他生物分子的区别

区分基本构件与连接方式，能避免把所有含氮的生物材料都视为同一类物质。

| 对象 | 主要构件 | 链中的连接方式 |
|---|---|---|
| DNA | 脱氧核糖核苷酸 | 磷酸二酯键 |
| 蛋白质中的多肽 | 氨基酸残基 | 肽键 |
| 几丁质 | N-乙酰葡萄糖胺残基 | β(1→4) 糖苷键 |

DNA 与 RNA 也不同：前者含脱氧核糖、常见碱基包括 T，后者含核糖、通常以 U 对应 T 的位置。“通常双链”是常见细胞 DNA 的结构描述，不是把双链规定为所有 DNA 分子的必要定义。
