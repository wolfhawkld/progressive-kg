# 蛋白质

> 由一条或多条多肽链组成的生物大分子，承担结构、催化、运输和调控等功能。

## 从氨基酸到多肽

蛋白质由一个或多个多肽链组成，多肽链则是[[氨基酸]]通过肽键按顺序连接形成的线性链。链的 N 端和 C 端给出方向；同样一组氨基酸按不同顺序排列，会形成不同的序列和分子。

| 结构层次 | 描述 | 主要决定因素 |
|---|---|---|
| 一级结构 | 氨基酸残基的线性序列 | 肽键连接的序列 |
| 二级结构 | 局部的 α 螺旋、β 折叠等 | 主链氢键和局部几何 |
| 三级结构 | 一条多肽的整体三维折叠 | 侧链相互作用、环境和修饰 |
| 四级结构 | 多条多肽亚基的组装 | 亚基之间的界面作用 |

这些层次是理解工具，不表示每个蛋白质都必须有四级结构。一个短肽、单链蛋白和多亚基复合物的结构层次并不相同。

## 功能的多样性

蛋白质的形状、表面化学和动态变化使其能够参与细胞中的多种工作。功能分类不是互斥的，同一个蛋白质可以同时承担结构和调控等角色。

| 功能类别 | 例子或作用 |
|---|---|
| 催化 | 酶降低反应活化能并提高特定反应速率 |
| 结构 | 形成细胞或细胞外部的支撑纤维和框架 |
| 运输 | 结合并移动离子、小分子或其他货物 |
| 信号与调控 | 接收信号、调节基因表达或控制通路活动 |
| 防御 | 识别或阻挡特定生物分子与外来成分 |

蛋白质不是“由 DNA 直接组成”的材料；DNA 保存信息，RNA 可以传递和解释信息，蛋白质是按信息生成、再由序列和环境决定构象的功能分子。部分蛋白质形成稳定折叠，部分天然无序蛋白或无序区域则保持动态构象，不能把稳定折叠当作蛋白质成立的必要条件。

## 遗传信息如何指定序列

典型表达路径是 `DNA → RNA → 蛋白质`。DNA 的编码序列先转录为 mRNA，mRNA 再由核糖体按[[遗传密码]]每三个核苷酸读取，依次加入对应的[[氨基酸]]。

具体的密码子—氨基酸映射和终止信号见[[遗传密码]]。前体 mRNA 可能经过剪接，蛋白质本身还可能经历化学修饰、伴侣辅助折叠或多链组装，因此“知道编码序列”不等于已经知道所有功能细节。

编码关系也不是“每三个 DNA 碱基自动对应一个成熟蛋白质残基”：需要确定转录产物、阅读框、起始与终止位置，并考虑非编码序列和 RNA 加工。

## 与其他生物大分子的边界

蛋白质的单体是氨基酸，连接方式是肽键；[[DNA]] 和 [[RNA]] 的单体是[[核苷酸]]，主链是糖—磷酸骨架；[[多糖]]的单体是单糖或其衍生物，通常以糖苷键连接。不同聚合物都能形成复杂三维结构，但化学构件和信息含义不同。

[[几丁质]]可以和蛋白质形成复合材料，例如节肢动物外被中的几丁质—蛋白质结构；这不意味着几丁质本身是蛋白质，也不意味着其中的结构蛋白由几丁质单体组成。

## 关系网络

- 组成：[[氨基酸]] — 氨基酸残基通过肽键连接形成多肽链
- 信息来源：[[DNA]] — DNA 编码区域为蛋白质序列提供遗传信息
- 信息中介：[[RNA]] — mRNA 将部分 DNA 信息带到翻译系统
- 规则：[[遗传密码]] — 密码子把 mRNA 核苷酸序列映射为氨基酸序列
- 对比：[[多糖]] — 蛋白质以氨基酸和肽键为主，多糖以糖单体和糖苷键为主
- 复合结构：[[几丁质]] — 几丁质可与蛋白质形成结构性复合材料
- 相关：[[基因]] — 部分基因通过 RNA 途径提供蛋白质序列信息
- 相关：[[翻译（生物学）]] — 多肽折叠、修饰或组装后可形成蛋白质
- 相关：[[酶]] — 大多数酶由多肽链折叠形成活性结构
- 相关：[[核糖体]] — 核糖体生成的多肽可进一步成为蛋白质
- 相关：[[肽键]] — 多肽折叠和组装后可成为蛋白质
- 相关：[[基因表达]] — 部分表达路径最终产生蛋白质
- 相关：[[蛋白质折叠]] — 蛋白质的氨基酸序列和多肽链是折叠对象
