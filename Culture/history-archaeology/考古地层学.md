# 考古地层学

> 依据堆积、切割与覆盖关系重建遗址形成顺序的考古记录与解释方法

## 层位与相对顺序

考古地层学把土层、坑、墙、铺面等可识别的堆积或界面作为记录单元，依据它们的形成和覆盖关系建立相对先后。未受扰动时，位于上方的堆积通常晚于被其覆盖的堆积；一个切穿旧层的坑或沟，其开挖活动晚于被切穿的层，但坑内填土还要按自身层位判断。

例如，若层 A 覆盖层 B，而坑 C 切穿 A 和 B，则可记录 B 早于 A、A 与 B 早于 C 的开挖。坑的填土可能包含从 A 或 B 带入的残留物，因此填土中的单件器物不能自动代表填土形成时的新制品。

## 矩阵记录与扰动边界

哈里斯矩阵把堆积和界面表示为节点，把覆盖、切割、相接等关系表示为有方向的边，从而把分散的现场记录组织成地层序列。它表达相对关系，不会单独给出公历年代；绝对年代仍需结合样品、类型学或其他测年证据。

洪水、火山活动、根系和动物洞穴、后来的挖掘以及人为搬运都会打乱原位关系。扰动层应记录切入、回填和混合范围；无法确认原位时，要把材料的出土位置与推断的形成时间分开。遗址底部也不必一概最早，关键是先检验是否存在倒置、再沉积或后期开挖。
