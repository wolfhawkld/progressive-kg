# 伊斯兰教

> 以独一真主、穆罕默德的先知使命和《古兰经》为核心的宗教传统。

## 起源与核心信仰

伊斯兰教作为历史宗教共同体形成于公元七世纪的阿拉伯半岛，与穆罕默德在麦加和麦地那的传教活动密切相关。

穆斯林信仰独一真主，并将穆罕默德视为先知和使者，而非被崇拜的神。他们把《古兰经》视为真主启示；这是对信仰内容的描述。伊斯兰传统也承认亚伯拉罕、摩西和耶稣等先知，但对耶稣身份的解释与主流基督教不同。

- “穆斯林”指信仰伊斯兰教的人，不是某个民族的名称。
- 阿拉伯语是《古兰经》的语言，但穆斯林并不限于阿拉伯人。
- 宗教启示的信仰宣认与历史文献的形成、传播问题应分别记录。

## 经典与主要传统

《古兰经》居于核心地位，圣训记录有关穆罕默德言行的传述；二者不是同一本书，圣训的传承、可靠性判断和解释也有差异。

逊尼派与什叶派的历史分歧涉及穆罕默德之后的领导继承和宗教权威，后来形成各自内部的多种传统。不能把分歧只写成现代政治对立，也不能认为任何一派在所有议题上完全一致。

苏菲传统重视内在修持与对真主的亲近，可与不同教派身份交叉，不宜机械列成与逊尼、什叶完全互斥的“第三派”。

## 实践与生活

五功是常用的实践概括，尤其见于逊尼传统的教学；其他传统也参与许多共同实践，但分类和解释未必完全相同。

| 实践 | 基本意义 |
|---|---|
| 念功 | 作信仰见证 |
| 礼功 | 日常礼拜 |
| 课功 | 按宗教规定履行财产施舍义务 |
| 斋功 | 莱麦丹月斋戒 |
| 朝功 | 在具备相应能力和条件时前往麦加朝觐 |

具体义务存在适用条件与豁免，不能从表格推出每个信徒每时每刻都以相同方式实践。阅读某地礼拜或节庆时，还应区分教义要求、地方习惯与个人选择。
