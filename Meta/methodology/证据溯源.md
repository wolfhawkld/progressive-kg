# 证据溯源

> 记录论断所依赖的来源、处理过程和责任主体以支持复核的方法。

## 记录可以复查的证据链

溯源把一个结论连接到其输入材料及生成过程，使后续读者能够定位核对。

W3C PROV 用实体、活动、主体及其关系描述来源。本库据此采用以下简化记录，不声称已实现完整 PROV 数据格式：

| 项目 | 本库记录方式 |
|---|---|
| 论断 | 写出可单独核对的一句话及适用范围 |
| 来源 | 地址、版本、章节或页码、核对日期 |
| 处理 | 区分摘录、概括、计算和推断 |
| 责任 | 记录修改者或审阅记录及修改原因 |

## 执行流程与限制

先按论断核对材料，再更新核验日期，避免只保存一个网址就声称整页已验证。

1. 找到直接支持论断的段落、数据或推导。
2. 标明材料究竟支持观察、解释还是假设。
3. 记录材料之间是否转载、共享数据或引用同一源头。
4. 来源变化时定位受影响论断，再决定修订或保留不确定性。

示例：三篇报道都转述同一次发掘，应保留共同源头。链条完整使它们可追查，但不自动使报道或历史解释为真。上述流程是本库操作建议，其效果尚未单独实测。
